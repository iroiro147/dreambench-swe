# Public History Reconstruction

The public Git graph was reconstructed on 2026-07-10 to remove reachable
objects and release assets that unintentionally contained raw operational
fixtures. This reconstruction does not change the frozen Paper A analysis or
reported results.

## Historical Releases

- The v2.0.0, v2.0.1, and v2.0.2 release records are retained for provenance.
- Their public artifact tarballs were withdrawn. Other release assets remain
  available where they passed the public-content audit.
- The v2.0.3 and v2.0.4 artifacts contained the sanitized replacement fixtures.
- v2.0.5 is the current, fully audited public release.

External clones or caches created before reconstruction cannot be revoked.
The withdrawn artifact SHA-256 values remain listed in the corresponding
release notices so prior citations can be identified without republishing the
affected bytes.
