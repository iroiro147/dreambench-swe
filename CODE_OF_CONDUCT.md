# Code of Conduct

DreamBench-SWE follows the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be precise, respectful, and evidence-led. Criticism of methods, claims, code,
and experimental design is welcome; personal attacks, harassment, and
discriminatory conduct are not.

For a confidential conduct concern, use the repository's [private reporting
form](https://github.com/iroiro147/dreambench-swe/security/advisories/new) and
begin the report title with `Conduct concern:`. Although GitHub labels this
surface as vulnerability reporting, it is the repository's enabled private
maintainer inbox. For threats or platform-wide abuse, also use GitHub's own
[reporting tools](https://docs.github.com/en/site-policy/acceptable-use-policies/github-bullying-and-harassment).
